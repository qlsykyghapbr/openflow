## 🤖 Overview

OpenFlow is a self-hostable visual programming environment for building AI pipelines, connecting LLMs, data sources, and APIs into repeatable automated workflows.

Whether you're a newcomer or a veteran, OpenFlow provides the tools you need to get the most out of your ai tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |
|---|---|
| **Self-Hosted** | Run entirely on your own infrastructure with full data control |
| **LLM Agnostic** | Connects to OpenAI, Anthropic, Mistral, and local Ollama models |
| **Node Editor** | Visual node-based editor for constructing complex AI chains |
| **API Export** | Export any workflow as a callable REST API endpoint |
